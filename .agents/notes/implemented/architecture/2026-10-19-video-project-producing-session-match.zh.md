# Agent Note: 把视频项目匹配到产出它的会话

Status: implemented

[English](2026-10-19-video-project-producing-session-match.md) | 中文

## 问题

视频 shell 模式列出 agent 写过的项目，而其旁的对话窗格显示的是用户碰巧身处其中的那个会话。选中一个项目并没有回到构建它的会话的途径，因为没有任何东西记录这一配对。`script.json` 不携带会话 id，项目目录也没有标记文件，而 `SessionHeader.cwd` 保存的是会话启动时所在的工作区根——绝非 agent 随后在其中创建的项目子目录——因此同一个工作区下的每个项目都匹配到相同的候选会话，仅凭目录无法在它们之间做出选择。用户自身的历史是这一配对唯一留存之处：构建某个项目的人在其中写过路径。

## 决定

该配对由会话日志已持有的证据推断得出，且浏览器提供切换而非自行切换。

`GET /api/video/project-session?path=<project>` 回答 `{ sessionId: SessionId | null }`。`findProducingSession` 按新近度优先遍历 `sessionQuery.listSessions()`，保留其记录的 `cwd` 在 `FileSystem.contains` 下包含该项目目录的会话，并向全文索引查询该目录相对该 `cwd` 的路径。相对拼写是关键选择：查询被引号包成一个 FTS5 短语，而 `unicode61` 分词器同等对待 `\` 与 `/` 并丢弃两者，因此一条查询即可匹配同一路径的绝对与相对两种拼写，既不读取任何日志行，也不依赖片段长度。最多探测 12 个候选，且新近者优先，因此一段长历史会把预算花在最可能的答案上。位于其会话自身 `cwd` 的项目在其之下没有可搜索的路径，因此最新的那个此类会话是唯一可得的答案，并且无需探测即被返回。

关闭了内容搜索的部署根本无法匹配任何项目，这是一处配置故障而非引用缺失，因此 `SESSION_QUERY_SEARCH_DISABLED` 会被重新抛出，而不是被折进 `null` 答案；其他任何探测失败都只是一个不可读的会话，搜索会继续。`dsh-video-app` 在把它交付为关闭的那些层之上以 `openAt: first-search` 打开索引，因此已发布的 profile 能够作答。

在浏览器中，该匹配是 roster 控制器快照上多出的一名成员 `sessionMatch`，在其仍为 null 时于每次轮询中再次询问，因为构建某项目的会话可能仍在写入匹配所读取的日志。`VideoSessionBanner` 把它渲染为对话的 `conversation.input.dock` slot 上的一张卡片，且只在一次点击时切换会话；当前对话已经就是该匹配时它保持隐藏，而控制器的 `start()` 停止器会清除该匹配，因此卡片不会跟随用户离开视频模式。

## 考虑过的替代方案

**把会话 id 记录在 `script.json` 中。** 否决，因为这仅覆盖该变更之后写出的项目，使每个既有项目都无法匹配，并把一个归宿主所有的事实交给 video preset 的 persona——agent 必须知道自身的会话 id 并正确写出它，宿主才能信任。

**仅按 `cwd` 祖先关系匹配。** 否决，因为祖先关系把语料收窄为一个集合而非一个答案：同一工作区下的每个项目共享相同的祖先，于是选择会落到新近度上，而只要用户在一个工作区里运行过两个会话，这就是错的。

**读取每个候选日志并在其中扫描该路径。** 否决，因为全文索引已能用一条短语查询回答同一个问题，而扫描是每次选择都要付出的语料量级 I/O，且只能找到恰好落在某个读取窗口内的路径。

**在选中时自动切换对话。** 否决，因为这会替换用户身处其中的对话并使其失去当前位置；卡片提供切换，由用户决定。

**在浏览器中用它已持有的会话列表匹配。** 否决，因为客户端的会话列表仅携带头部，因此它不持有任何可供匹配的证据；语料与索引归宿主所有。

## 后果

视频界面在不新增任何已持久化事实的前提下获得了回到项目历史的途径，代价是一个被推断出的答案：没有任何留存日志引用的项目回答 `null` 且不显示卡片，而所有会话都提及该路径的工作区则回答其中最新的那个。宿主数据面现在依赖 `ctx.sessionQuery` 并依赖内容搜索处于打开状态，因此挂载它的组合包携带该覆盖，而后一层关闭索引会把该路由变成一次失败，而非静默的无匹配。对话的输入器 dock 多出第二名贡献者，这确立了 dock 作为功能插件可以提供会话作用域动作、而无需拥有对话界面本身的位置。
